# KG Corrida LIVE

Jogo HTML5 vertical para TikTok LIVE com Node.js, Socket.IO e biblioteca comunitária não oficial.

## Render

Use Web Service Node.js, build `npm install`, start `npm start`, health `/health`. Configure `ADMIN_TOKEN` como segredo no Render. Opcionalmente configure `TIKTOK_USERNAME`.

## Uso

Abra o endereço HTTPS do Render no Safari do iPhone. Toque **Demo** para testar. Para conectar LIVE ativa, toque ⚙️, informe seu usuário TikTok sem @ e o token de administrador. Nunca informe senha do TikTok.

## Limitações

A biblioteca `tiktok-live-connector` não é oficial e pode falhar. Comentários, curtidas e presentes não estão garantidos. TikTok pode restringir LIVE e compartilhamento de tela no iPhone. Render Free pode suspender após inatividade. Não há garantia de transmissão simultânea no mesmo aparelho.
